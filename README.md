# CloudDeck releases

CloudDeck is a desktop app for browsing AWS EC2 fleets. This repository holds its public side:

- **Releases**: download builds from the [Releases](https://github.com/eginez/clouddeck-releases/releases) page. The app's updater checks here too.
- **License**: see [LICENSE.md](LICENSE.md). For a commercial license, [open a request](https://github.com/eginez/clouddeck-releases/issues/new?template=commercial-license.yml).
- **Website**: the source of [clouddeck.dev](https://clouddeck.dev) lives in `website/`.
- **Docs**: [extensions](docs/extensions.md), [troubleshooting](docs/troubleshooting.md), [release notes](docs/release-notes/).
