# CloudDeck 0.3.0

CloudDeck is a desktop browser for your AWS and Google Cloud instances, in one window.

## New

- A new onboarding window replaces the Connect window. It finds your AWS profiles and Google Cloud credentials, shows the account you are signed in as and any config errors, and lets you pick regions and zones before the first load.
- Google Cloud can sign in with a service-account key as well as gcloud application-default credentials.
- AWS and GCP config folder settings: point CloudDeck at a credentials folder other than the default.
- The region and zone picker handles parent and child scopes of any depth.

## Changed

- CloudDeck is now licensed under the PolyForm Small Business License 1.0.0. See LICENSE.md.
- Releases, the license, the docs and clouddeck.dev now live in github.com/eginez/clouddeck-releases. The updater checks there.
- Plugins talk to the app over MessagePack. Plugins built for 0.2.x must be rebuilt.
- Upgraded the UI toolkit (GPUI).

## Fixed

- Region and zone choices made in another window are no longer overwritten when a window saves.
- The query box no longer offers suggestions inside an unclosed quote.
- Plugin names show above their version in the Plugins list.

## Known limits

- The app is not notarized: the first time, right-click CloudDeck and choose Open. The Homebrew cask does this for you.
- Installing third-party plugins is switched off in this release.
