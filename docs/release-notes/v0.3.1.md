# CloudDeck 0.3.1

## Fixed

- The Linux build starts on current distributions again. 0.3.0 for Linux was built against a newer system library (glibc 2.43) than most installed systems have, so it failed to start on Ubuntu 24.04 and similar. 0.3.1 needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later).

No other user-visible changes from 0.3.0. See the 0.3.0 notes for what is new in the 0.3 line.
